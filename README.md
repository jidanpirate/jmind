# jmind — 本地优先的思维导图工具

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue.svg)](https://pages.github.com/)

一个轻量级、纯前端的在线思维导图工具。所有数据存储在浏览器本地，无需注册登录，开箱即用。

## ✨ 功能特性

### 核心编辑
- **可视化画布** — 基于 Canvas 的流畅渲染，支持无限缩放和平移
- **拖拽排序** — 拖拽节点到目标位置，支持作为子节点或兄弟节点插入
- **节点操作** — 添加子节点/兄弟节点、删除、编辑文本、折叠/展开
- **右键菜单** — 丰富的上下文操作菜单
- **节点颜色** — 自定义节点颜色，支持多种预设配色
- **字体样式** — 选中节点后可调整 粗体 / 斜体 / 下划线 / 字号（12–32）/ 字体（默认/宋体/黑体/楷体/等宽），画布与大纲同步生效

### 效率工具
- **撤销 / 重做** — 完整的操作历史记录（Ctrl+Z / Ctrl+Y）
- **节点搜索** — 实时搜索并高亮匹配节点（Ctrl+F）
- **复制 / 粘贴** — 复制节点子树，粘贴为目标节点的子节点（Ctrl+C / Ctrl+V）
- **节点复制** — 快速创建节点副本（Ctrl+D）
- **自动保存** — 编辑后 2 秒自动保存，离开页面时自动保存
- **适应画布** — 一键缩放至全部内容可见

### 视图模式
- **思维导图视图** — 基于 Canvas 的可视化画布，支持拖拽、缩放、动画
- **大纲视图** — 类 XMind 的缩进列表大纲，支持折叠/展开、行内编辑、方向键导航、**拖拽调整层级与顺序**、Shift+Tab 提升层级，与画布视图共享同一份数据，可一键来回切换（工具栏「大纲」按钮 / `Ctrl+Shift+O`）

### 导入导出
- **导出 .json** — 标准 JSON 格式的思维导图文件，可跨设备迁移
- **导出 PNG** — 2 倍高清图片导出，适合分享和演示
- **导入文件** — 支持导入 .json / .jmind 格式文件
- **数据备份** — 设置页可一键导出全部本地数据

### 界面体验
- **中英双语** — 设置页切换语言即时生效（中文 / English），界面、菜单、提示全覆盖
- **双维度主题** — 外观模式（浅色 / 深色）与主题色（蓝 / 绿 / 粉 / 紫 / 橙）自由搭配，共 10 种组合，自动兼容旧版主题设置
- **流畅动画** — 节点弹性入场、选中呼吸光环、悬停放大、浮动快捷菜单、页面与卡片入场、按钮光泽等细腻动效，并尊重系统"减少动态效果"设置
- **响应式** — 支持桌面端和移动端触摸操作
- **快捷键** — 丰富的键盘快捷键，提升编辑效率
- **状态栏** — 实时显示节点数量和缩放比例

## 🚀 快速开始

### 在线使用
访问 [https://jidanpirate.github.io/jmind/](https://jidanpirate.github.io/jmind/) 即可直接使用，无需安装。

### 本地运行
```bash
# 克隆仓库
git clone https://github.com/jidanpirate/jmind.git
cd jmind

# 方式一：直接用浏览器打开 index.html
# 方式二：启动本地服务器（推荐）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 添加子节点 |
| `Enter` | 添加兄弟节点 |
| `Delete` / `Backspace` | 删除选中节点 |
| `F2` | 编辑节点文本 |
| `Space` | 折叠/展开节点 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+S` | 保存 |
| `Ctrl+F` | 搜索节点 |
| `Ctrl+C` | 复制节点 |
| `Ctrl+V` | 粘贴节点 |
| `Ctrl+D` | 复制节点为副本 |
| `+` / `=` | 放大 |
| `-` | 缩小 |
| `0` | 适应画布 |
| `Ctrl+Shift+O` | 切换 大纲视图 / 思维导图视图 |
| `↑` `↓` | （大纲视图）上/下移动选中节点 |
| `←` `→` | （大纲视图）折叠/展开，或跳到父节点/子节点 |
| `Shift+Tab` | （大纲视图）提升层级 / 减少缩进 |
| `Esc` | 关闭菜单/搜索/取消编辑 |
| 双击节点 | 编辑文本 |
| 右键节点 | 打开上下文菜单 |

## 📁 项目结构

```
jmind/
├── index.html          # 首页（最近文件列表）
├── editor.html         # 思维导图编辑器
├── settings.html       # 设置页面
├── css/
│   ├── common.css      # 共享样式（主题变量、导航、按钮、Toast）
│   ├── index.css       # 首页样式
│   ├── editor.css      # 编辑器样式
│   └── settings.css    # 设置页样式
├── js/
│   ├── storage.js      # 本地存储管理（文件 CRUD、设置）
│   ├── i18n.js         # 国际化（中英词典、翻译函数）
│   ├── mindmap.js      # 数据模型、节点操作、撤销历史、剪贴板
│   ├── layout.js       # 树状布局引擎
│   ├── renderer.js     # Canvas 渲染器、命中检测、PNG 导出
│   ├── outline.js      # 大纲视图（缩进列表、行内编辑、键盘导航）
│   ├── editor-app.js   # 编辑器主逻辑（事件、快捷键、工具栏、视图切换）
│   ├── index-app.js    # 首页逻辑
│   └── settings-app.js # 设置页逻辑
├── .nojekyll           # GitHub Pages 配置（禁用 Jekyll）
├── .gitignore
└── README.md
```

## 🛠️ 技术栈

- **纯原生 HTML / CSS / JavaScript** — 无框架依赖，无构建步骤
- **Canvas 2D API** — 高性能节点和连线渲染
- **localStorage** — 本地数据持久化
- **CSS 自定义属性** — 主题系统实现

## 📄 文件格式

导出的 `.json` 文件为标准 JSON 格式，结构如下：

```json
{
  "format": "jmind",
  "version": "1.1",
  "created": "2026-01-01T00:00:00.000Z",
  "modified": "2026-01-01T00:00:00.000Z",
  "root": {
    "id": "node-1-abc",
    "text": "中心主题",
    "color": "#E8825A",
    "collapsed": false,
    "children": [
      {
        "id": "node-2-def",
        "text": "分支 1",
        "color": "#5B9BD5",
        "collapsed": false,
        "children": []
      }
    ]
  }
}
```

## 🔒 隐私说明

- 所有思维导图数据仅存储在你的浏览器本地（localStorage）
- 不会向任何服务器上传或同步数据
- 清除浏览器数据将导致文件丢失，请定期使用"导出备份"功能
- 建议定期导出重要的思维导图文件
